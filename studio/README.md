# ARQ. studio site

Files: index.html, config.js, assets/ (logos, covers, work images), media/ (motion videos).

## Publish free on GitHub Pages
1. Create a new public repo on GitHub, e.g. `arq-studio`.
2. Upload everything in this folder (index.html, config.js, README.md, assets/).
3. Settings > Pages > Source: Deploy from a branch > main / root > Save.
4. Live in 1-2 minutes at https://<your-username>.github.io/arq-studio/

## Enquiry form
Uses Web3Forms. The key in config.js is your existing one, so enquiries go to your email.
